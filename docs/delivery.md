## Foundation acceptance

- Clean install from lockfile; formatting/lint/strict type checks; web production build and Android Metro export succeed.
- Bangla opens first; English changes all visible interface text; both apps use shared keys.
- Navigation destinations and More work; unavailable actions are labeled. V3-inspired dashboard, catalog, directory, basket, expense, invoice and fixed estimator compositions use U3-approved synthetic snapshots, never operational totals or pretend saves/payments.
- Demo snapshots are imported separately and never read customer storage. Mixed Bangla/Latin input stays a string; invalid values show clear feedback in the development-only preview.
- Dhaka date helper passes UTC-midnight boundaries regardless of host timezone. It is a display helper, not a server business clock.
- Loading/empty/error/denied can be previewed honestly. Keyboard focus and skip link remain usable, zoom is unrestricted, long pages/nav can scroll.
- Verify 375×667, 390×844, 768×1024, 1024×768 and 1440×900 browser layouts, plus real 100%/125%/150%/200% zoom (U4 closeout); earlier 400% accessibility follow-up remains useful. Record blocked zoom separately from viewport reflow. Device tests must cover Bangla shaping, Android Back, keyboard/scroll, TalkBack and large font settings. Export success alone does not pass device acceptance.
